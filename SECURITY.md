# Security policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** feature if it is available for this repository. If it is not available, open an issue with only a brief, non-sensitive description and ask for a private contact channel. Do not publish exploit details or credentials in a public issue.

Telegram API Diff only fetches a public schema URL and writes local JSON/Markdown files. It does not require Telegram credentials, bot tokens, API hashes, or other secrets.
